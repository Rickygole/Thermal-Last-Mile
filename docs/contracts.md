# Data contracts

Frozen. The web client builds against this schema, not against the pipeline.
Every file listed here lives in `web/public/data/` and is committed.

## segments.geojson

FeatureCollection. Geometry is LineString in EPSG:4326. One feature per walk segment
of roughly 20 metres.

```json
{
  "id": "kirby_8500",
  "name": "Kirby Dr, 8500 block",
  "len_m": 214,
  "approach": "metrorail_stadium_park",
  "degmin": { "15": 96.4, "17": 88.1, "19": 41.0, "21": 12.7 },
  "degmin_lo": { "15": 78.2, "17": 71.4, "19": 32.1, "21": 8.9 },
  "degmin_hi": { "15": 114.6, "17": 104.8, "19": 49.9, "21": 16.5 },
  "wbgt": { "15": 34.8, "17": 34.1, "19": 32.6, "21": 30.4 },
  "shade_frac": { "15": 0.00, "17": 0.04, "19": 0.31, "21": 1.00 },
  "fans": 11200,
  "svi": 0.78,
  "canopy_pct": 0.0,
  "treatable": ["sail", "tree", "awning"]
}
```

`degmin` is degree-minutes above WBGT 32 accumulated by one fan traversing the
segment at 1.3 m/s. `degmin_lo` and `degmin_hi` bound the 90 percent interval.

## solutions.json

```json
{
  "meta": { "step": 25000, "cap": 2000000, "method": "greedy_submodular" },
  "path": {
    "750000": {
      "set": ["kirby_8500#sail", "murworth#tree"],
      "averted_degmin": 1090400,
      "averted_per_fan": 128,
      "cost_per_degmin": 0.69,
      "fans_below_threshold": 11900,
      "spent": 748000
    }
  }
}
```

Keys of `path` are budget levels as strings, from 0 to 2000000 in steps of 25000,
81 levels. `averted_degmin` is monotone non decreasing in budget.


## shade_{hh}.png

Baked shade masks, one per kickoff hour in 15, 17, 19, 21. Greyscale PNG, white is
shaded. Georeferenced by the bounds in `meta.json.raster_bounds`, drawn as a deck.gl
BitmapLayer at opacity 0.35.
